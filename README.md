# Projeto: Árvore Binária em C

## Descrição

Este projeto implementa uma estrutura de dados de Árvore Binária em linguagem C. O objetivo é demonstrar operações básicas como inserção, busca, remoção e travessias (pré-ordem, em-ordem e pós-ordem) em uma árvore binária.

## Estrutura do Projeto

- `codebase/binary_tree.c` e `codebase/binary_tree.h`: Implementação e definição das funções e estruturas da árvore binária.
- `codebase/main.c`: Função principal para testar as operações da árvore.
- `codebase/Makefile`: Facilita a compilação do projeto.

## Funcionalidades

- Inserção de nós na árvore binária.
- Busca de elementos.
- Remoção de nós.
- Travessias: pré-ordem, em-ordem e pós-ordem.
- Impressão da árvore.

## Como Compilar

Para compilar o projeto, utilize o comando:
```
make
```

O executável será gerado na pasta `output/` ou no diretório principal.

## Como Executar

Após compilar, execute o programa com:
```
./codebase/my_program.exe
```
ou
```
./output/binary_tree.exe
```
